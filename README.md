# CloudRescue
AWS Based cloud Operation, failure recovery cost optimization and AI-assisted incident Analysis Platfrom 

*Project Objectives

- Design and deploy AWS cloud infrastructure.
- Build and operate a Linux-based web application.
- Monitor infrastructure health and application performance.
- Simulate controlled cloud infrastructure failures.
- Investigate incidents and identify potential root causes.
- Implement and verify safe recovery procedures.
- Analyze AWS resource usage and optimize costs.
- Develop Python-based cloud automation.
- Explore AI-assisted incident analysis.
Architecture Overview


*The planned architecture includes:

- Amazon VPC — Network isolation and infrastructure design.
- Amazon EC2 — Application servers.
- Application Load Balancer — Traffic distribution and health checks.
- Amazon RDS — Managed relational database.
- Amazon S3 — Storage for project artifacts, reports, and selected backups.
- AWS IAM — Identity and access management.
- Amazon CloudWatch — Metrics, logs, and alarms.
- AWS CloudTrail — AWS API activity investigation.
- AWS Config — Resource configuration tracking.
- Amazon SNS — Alerts and notifications.
